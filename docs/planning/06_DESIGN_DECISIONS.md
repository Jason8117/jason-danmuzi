## 1. 요약

콜비의 디자인 콘셉트를 04의 "일은 조용히 해 두고, 내 차례만 분명하게"에서 05의 **Quiet Intelligence**로 넓힌다. 지능을 화려하게 드러내지 않고 정제된 화면으로 전달한다는 뜻이며, 04의 "차분함·내 차례 강조" 원칙은 그대로 이어받는다.

세 가지 핵심 경험(05 §9)을 제품 구조의 기준으로 삼는다.

| 핵심 경험 | 뜻 | 화면 |
|---|---|---|
| Today 대시보드 | 앱을 열면 무엇을 물을지 고민하게 하지 않고, 비서가 먼저 오늘 할 일을 알려 준다 | 오늘(SCR-H01) |
| 음성 우선 비서 | 어느 화면에서든 가운데 Orb를 눌러 말이나 글로 부탁한다 | AI 비서(SCR-A01) |
| 업무 실행 관리 | 비서가 무엇을 하고 있는지 단계로 보여 주고, 중요한 결정은 사용자에게 묻는다 | 업무 실행(SCR-T02), 통화 중(SCR-T08) |

디자인 정체성 세 가지(05 §9)는 03 §2.1의 비서 성격과 이렇게 대응한다.

| 정체성 | 뜻 | 03·04에서 이미 있는 장치 |
|---|---|---|
| Proactive | 부탁하기 전에 필요한 일을 알려 준다 | (신규) 오늘의 브리핑, 제안 업무 |
| Action-oriented | 답만 하지 않고 실제로 처리한다 | 전화 대행, 계획 카드, 결과 후속 행동 |
| Trustworthy | 하는 일을 보여 주고 중요한 결정은 맡긴다 | 확인 지점 C-1~C-8, 신뢰 줄, 결정 기록 |

### 3.4 사용 비율과 모양

- 사용 비율: 무채색 70 · Midnight 20 · 강조(인디고) 10. 화면 전체를 인디고로 채우지 않는다. 인디고는 AI와 직접 주고받는 곳과 주 행동에만 쓴다(05 §4).
- 글자 단계: 화면 제목 28/Bold, 묶음 제목 18~20/SemiBold, 본문 15~16/Regular, 보조 12~13(05 §3). 04 §4.2의 `headlineSmall`·`labelMedium` 추가 결정은 유지한다.
- 간격 4·8·12·16·24·32, 화면 좌우 여백 20, 카드 모서리 20, 버튼 모서리 16, 누르는 영역 48 이상(05 §3, 04 §4.3과 같음. 화면 좌우만 16 → 20).
- 테두리는 1px 옅은 선, 그림자는 거의 쓰지 않는다(05 §6). 04의 `AppCard` 그림자는 선으로 바꾼다.
- 아이콘: Lucide 계열 선 아이콘, 굵기 1.5~2(05 §6). Flutter 구현에서는 같은 모양의 선 아이콘 묶음을 쓰고, 04 §4.5의 "선택 상태만 채운 모양" 규칙은 유지한다. 패키지 선정은 SPEC-SHELL-001 착수 때 한다.
- 움직임: 부드럽고 절제되게(05 §6). 04 §4.4의 시간 값(250·150·400 ms)과 움직임 줄이기 규칙을 그대로 쓴다.

### 4.1 핵심 흐름(목업 1행)

```
오늘(H01) ─[가운데 비서 / 전화 대신하기]→ AI 비서(A01) ─[말하기 끝]→ 장소 선택(H02) ─→ 계획 확인(H04)
```

- 결과의 [통화 기록]은 기록(R01)으로 간다.

### 4.2 문구

05의 영문 미리보기 문구를 해요체로 옮긴 기준 문구다. 04 §2.3 표에 더한다.

| 자리 | 문구 |
|---|---|
| 오늘 인사 | 좋은 아침이에요, 지은 님. / 오늘도 제가 함께할게요. |
| 브리핑 | 오늘 중요한 일이 3개 있어요. / 브리핑 확인하기 → |
| 부탁 묶음 제목 | 비서에게 부탁하기 (전화 대신하기 · 일정 관리 · 메일 확인 · 정보 찾아보기) |
| 승인 묶음 제목 | 확인이 필요해요 |
| AI 비서 | 무엇을 도와드릴까요? / 말씀해 주시면 제가 대신 처리할게요. |
| Orb 상태 | 기다리고 있어요 · 듣고 있어요 · 처리하고 있어요 · 말하고 있어요 |
| 업무 실행 안내 | 승인이 필요한 일은 확인 없이 실행하지 않아요 |
| 결과 제목 | 부탁하신 업무를 완료했어요. |
| 슬로건(온보딩) | Less to do. More to live. / 복잡한 일은 비서에게, 소중한 시간은 당신에게. |

04 §2.3의 "홈 입력 제목: 무엇을 맡길까요?"는 AI 비서 화면이 생기며 "무엇을 도와드릴까요?"로 바뀐다. 04가 피할 예로 둔 문구지만, 05와 승인된 목업을 따라 비서 화면에서는 이 문구를 쓴다. 오늘 화면에는 입력칸 제목을 두지 않는다.
